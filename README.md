💳 Credit Card Financial Dashboard – Power BI
📌 Project Overview

The Credit Card Financial Dashboard is a Power BI project designed to analyze customer credit card usage and digital spending behavior. The dashboard provides actionable insights into transaction trends, customer segmentation, card performance, and digital channel adoption to support data-driven decision-making in the financial services domain.

This project focuses on identifying high-value customers, spending patterns, platform usage, and business growth opportunities, while also helping stakeholders monitor potential credit risk indicators.

🎯 Project Objectives

Analyze customer spending behavior across digital platforms

Identify trends in monthly transaction volumes

Evaluate card performance by card family and customer segment

Understand customer engagement and retention patterns

Provide insights for targeted marketing and business strategy

📊 Key Metrics Covered

Total Spend

Number of Transactions

Active vs Dormant Customers

Card Distribution

Platform-wise Digital Spend

Monthly Spend Trends

Customer Cohort Retention

🗂️ Dataset Description

The dataset contains credit card customer information including:

Customer demographics

Card type and customer segment

Transaction amount and date

Platform usage (Web, iOS, Android)

Digital spending details

Data was sourced from CSV/Excel files and processed using Power BI.

🔧 Data Preparation & Transformation
1. Data Loading

Imported structured datasets into Power BI using Power Query

Validated column mappings and data types

2. Data Cleaning

Handled missing and null values

Standardized field names and formats

Removed inconsistencies in categorical values

3. Data Structuring

Segmented data by:

Card family (Premium, Gold, Platinum)

Customer segment (Diamond, Gold, Platinum)

Platform usage (Web, iOS, Android)

Created calculated measures for KPIs and trends

📈 Dashboard Features & Insights
🔹 Market Insights

Web platform dominates digital spending (92%)

Multi-platform users show higher engagement and spend

🔹 Transaction Trends

Stable transaction volume with seasonal peaks

Forecast indicates consistent future growth

🔹 Customer Cohort Analysis

Strong retention among web users

Mobile users show gradual growth and consistency

🔹 Card Family-wise Spend

Premium cards generate the highest digital spend

Gold cards show strong mass adoption

🔹 Customer Segment-wise Spend

Diamond customers contribute the highest revenue

Platinum segment presents upselling opportunities

💡 Business Recommendations
